## 1. Save Text Analysis

Saves a new text analysis result to the database.

**Endpoint:** `POST /api/analysis/text`  
**Authentication:** Required (Bearer Token)

### Request Body

- `client_id`: (string) Analysis UUID generated by the frontend.
- `result`: (object) The text analysis result.

### Success Response (200 OK)

Returns the created `analysis_id`.

```json
{
  "is_success": true,
  "message": "Text analysis saved successfully",
  "data": 123,
  "status_code": 200,
  "timestamp": "2026-04-14T20:42:00Z"
}
```
